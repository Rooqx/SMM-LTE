# Phase 3: Creative & Multi-Platform Production Blueprint

## 1. Phase Overview & Strategic Objective

### Purpose
Phase 3 executes the approved weekly topic angles from Phase 2. It generates platform-native, high-converting creative copy, visual briefs, and video scripts while strictly adhering to the Brand DNA (`.agents/brand/*.md`).

### Core Production Formats
1. **Viral Hooks & Openers**: High-tension opening lines designed to stop the scroll.
2. **Platform-Native Copywriting**: Tailored text for LinkedIn, X (Twitter), and Instagram/Facebook.
3. **Slide-by-Slide PDF Carousels**: Structured visual briefs (Cover, Body, CTA) with design directions.
4. **Short-Form Video / Reels Scripts**: 30–60 second video scripts with spoken audio, on-screen text overlays, and B-roll directions.

### The X (Twitter) Tier Rule (Crucial)
- **Standard / Free X Account**: The agent enforces a strict **280-character maximum per tweet**. Long-form ideas are automatically partitioned into a numbered **4–6 tweet thread** with clear hook continuity.
- **X Premium / Paid Account**: The agent can format the output as a **single long-form post** (up to 25,000 characters) with bold headers and bullet lists.

### 🛠️ Curated Skill 1: `viral-hook-engine`
- **Primary Sources**: `hook-generator` (*3.1k likes*), `hook-writer-sms` (*social-media-skills*).
- **Core Rules**:
  - Employs the **2-Line Hook Formula**: Line 1 (max 40 chars, unexpected fact/metric) + Line 2 (max 40 chars, contrast/tension line).
  - Automatically generates **3 hook variations** for every post (Contrarian, Number-led, Transformation) so the user can select their favorite.

### 🛠️ Curated Skill 2: `multi-platform-copywriter`
- **Primary Sources**: `post-writer` (*3.1k likes*), `thread-writer-sms` (*social-media-skills*), `caption-writer-sms` (*social-media-skills*), `copywriting` (*marketingskills*).
- **Platform Execution Standards**:
  - **LinkedIn**: Short sentences, 1-line paragraph spacing, authentic industry perspective, zero robotic buzzwords (*delve, leverage, game-changer*), closing takeaway.
  - **X (Twitter)**: Standalone high-reply hooks or 4–6 tweet threads with a strong call-to-action tweet at the end.
  - **Instagram & Facebook**: First 125 characters front-loaded before the "more" cut-off, 1–3 emojis max, save/share CTA, and 5–8 targeted niche hashtags.

### 🛠️ Curated Skill 3: `carousel-visual-director`
- **Primary Sources**: `gemini-carousel` (*3.1k likes*), `carousel-writer-sms` (*social-media-skills*), `graphic-designer` (*3.1k likes*).
- **Slide Architecture**:
  - **Slide 1 (Cover)**: Big bold hook, high contrast, brand badge.
  - **Slides 2–6 (Content)**: Strict **15-word limit per slide**, 1 core idea per slide, visual layout cues (icons, diagrams, callout boxes).
  - **Final Slide (CTA)**: High-converting action (Follow + Repost + Lead Magnet link).
  - **Visual Prompts**: Includes technical image generation prompts for background assets / diagrams.

### 🛠️ Curated Skill 4: `short-form-video-scripter`
- **Primary Sources**: `reels-scripting` (*3.1k likes*), `video` (*marketingskills*).
- **3-Column Production Format**:
  | Time Code | Spoken Audio Script | On-Screen Text Overlay | Visual & B-Roll Cues |
  | :--- | :--- | :--- | :--- |
  | **0:00 - 0:03** | "Stop doing [Mistake]..." | STOP DOING THIS ❌ | Talking head zooms in / fast cut |
  | **0:03 - 0:30** | [Core teaching point] | [Key metric / keyword] | Screen-recording or product demo |
  | **0:30 - 0:45** | "Comment 'GUIDE' below..." | GET THE FREE CHEAT SHEET 👇 | Pointing down to caption |
