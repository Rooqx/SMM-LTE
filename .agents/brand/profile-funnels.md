### C. Experience Section (Storytelling Format: Context > Challenge > Action > Result)

#### Role 1: Senior AI & Full-Stack Engineer (Contract / Consulting)
```text
Fast-growing startups often struggle to move beyond fragile AI demos into production-ready software.

I stepped into multiple client codebases where linear LLM prompt chains were timing out and causing silent state corruption under concurrent user load.

Rather than patching prompt strings, I re-architected the workflows into deterministic finite state machines with PostgreSQL checkpoints, Zod runtime validation, and automated retry budgets.

This eliminated unhandled JSON parse exceptions, reduced LLM token spend by over 40%, and allowed clients to deploy reliable AI agents into customer-facing production.
```

#### Role 2: Full-Stack Software Engineer
```text
The product was experiencing noticeable frontend re-render lag and frequent database connection spikes during peak marketing launches.

I diagnosed the root bottlenecks: unmemoized object references triggering cascading React re-renders, and serverless functions exhausting PostgreSQL connection pools.

I introduced PgBouncer transaction pooling, optimized composite B-tree indexing on high-traffic queries, and refactored client-state boundaries.

The result was a 65% drop in database CPU utilization, sub-100ms API response times, and zero connection dropouts during high-volume spikes.
```
